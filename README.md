# Build In Social

Social media distribution partner for indie developers and SaaS founders. Generates platform-native content (YouTube Shorts, Instagram Reels, LinkedIn, X) around your domain presence — manual or autopilot.

## Setup

```bash
cp .env.example .env.local   # fill in your values
pnpm install
pnpm dev
```

## Stack

Next.js 16, React 19, TypeScript, Base Web, Tailwind CSS v4, Framer Motion, Clerk, Stripe, Anthropic Claude, ElevenLabs, Cloudflare R2, Upstash Redis.

# Product Rules — Never Break These

## Phase 1 Hard Constraints

### Avatar Mode
- DISABLED in Phase 1
- Show everywhere with "Coming soon" badge + waitlist CTA
- No HeyGen API code whatsoever — not even installed, not even a stub

### Faceless Mode
- This IS the entire product in Phase 1

### Content Model
- Domain-presence first — not ship-announcements
- Users set niche/domain ONCE during onboarding
- Each week: TWO modes only

**Manual mode:**
- User shares something specific (feature shipped, lesson, opinion, case study, tool review, debugging story)
- Quality gate (3 specific questions) is MANDATORY — never skippable
- Never generate a script without quality gate output

**Autopilot mode:**
- User has nothing to share → Build In Social generates a full week automatically
- Draws from: niche + voice, trending domain topics, evergreen angles, pre-built content series
- Bypasses quality gate — AI provides its own specificity
- Market as FIRST-CLASS feature, not a fallback

### Video Duration
- Build In Social sets duration based on platform — user CANNOT choose
- Show chosen duration in UI with optional override requiring a click

### Platforms
- Only 4: YouTube Shorts, Instagram Reels, LinkedIn, X
- Reddit = NEVER
- TikTok = NEVER (Phase 1 or any session unless explicitly told otherwise)

### Intelligence Panel
- Hidden until user has 5+ published videos with metrics

### Claude API Usage
- Haiku: scripts, labelling, quality gate, autopilot suggestions
- Sonnet: pSEO articles + intelligence summaries ONLY

### Framing
- Always "Build In Social is creating" — NEVER "generate video"
